美东时间7月27日，英伟达又搞了个大动作 🚀

他们宣布把NVIDIA Agent Toolkit给升级了，加入了PhysicsNeMo和CUDA-X库。简单说，就是让AI不仅能聊天、写代码，还能帮工程师搞物理模拟和设计。

Agent Toolkit是英伟达去年推出的一个工具包，专门用来开发AI代理（就是那种能自己干活、做决策的AI）。这次更新后，工程师可以用它来做更复杂的物理仿真，比如模拟流体、结构力学这些，不用再手动调参数了。

CUDA-X库大家应该不陌生，是英伟达的加速计算库集合。这次整合进去，意味着AI代理可以直接调用这些高性能计算资源，处理工程数据的速度会快很多。

英伟达说，这套工具的目标是“改变世界工程设计的方式”。听起来挺宏大，但逻辑其实很直接：让AI代理帮人类做那些重复、耗时的工程计算，把精力留给创新。

目前这套工具已经开放给开发者了，具体效果怎么样，还得看实际应用。不过从股价走势看，市场对英伟达在AI+工业领域的布局还是挺买账的。
